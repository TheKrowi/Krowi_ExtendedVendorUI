# Filters

From `CLAUDE.md`, Architecture, which keeps the summary; the rest of the architecture and the taint rules are there.

- **Filters** (`Filters.lua`): custom filter ids `KrowiEVU_LE_LOOT_FILTER_*` (100 and up) next to Blizzard's `LE_LOOT_FILTER_*`. The active filter is the addon's own (`filters:GetFilter`, `SetFilter`, `SyncFilter`, `RegisterListener`); on Retail and Forever `SetFilter` also passes the same value to the real `SetMerchantFilter`, custom ids included, and the client-side `Validate` filters what the server returns; the server treats the custom ids like All (`/kevutest`'s server list check, 2026-10-24, at a vendor with gear for every armor type). `BuildList` also applies the Gear options (`ValidateGear`: only usable, sub-optimal body armor below the best armor proficiency `C_SpellBook.IsSpellKnown` reports, minimum quality; weapons and armor only, every client; and the item level range, `Gear.MinItemLevel` and `MaxItemLevel` with 0 off, from the level the vendor's link carries, only where `filters.ItemLevelShown`: Retail, Forever and Mists, #107) and records per character which recipe items a vendor shows that it knows (`RecordRecipe`, once per item per visit, cleared on `MERCHANT_CLOSED`), account-wide in `KrowiEVU_Filters`'s AceDB `global.KnownRecipes["Name-Realm"]`, which Hide collected, Recipes my other characters know reads. Hide collected Recipes, Illusions and Other (items in no category, `filters.IsOther`) read one check, `filters.IsKnown`: the item's own Already known line (`filters.IsKnownLine`: `ITEM_SPELL_KNOWN` or `ERR_COSMETIC_KNOWN`, case ignored, since the game also writes "Already Known", #126; not `USED`, the trainer filter's label), from `C_TooltipInfo` on Retail and Forever (an item a recipe makes is inlined there too, from a `NestedBlock` line up to the recipe's own last `ItemSpellTriggerLearn` line, and `filters.GetNestedLines` leaves it out on every client) and from a hidden `KrowiEVU_ScanTooltip` on the Classic clients (no template: `GameTooltipTemplate` would hide and reset Blizzard's shared shopping tooltips from addon code), which have no `C_TooltipInfo` item getters and inline a recipe's crafted item from a line starting with a line break, where the check stops (Already Known #19). An uncached item reads as unknown, asks for its data and the list is built again when it arrives, as the sorts do; nothing is cached (#62). `BuildList` ends with `filters:SortList` (#55): the saved `Sort` (`By` one of `filters.SortKeys`: Vendor, Name, GoldPrice, TokenPrice, Quality; `Reverse`), each key with its natural direction, items without a value last, ties in the vendor's order; Token price and the token banner both follow `filters:GetTokenOrder`, each currency or cost item in the order it first appears in the vendor's full list. Listeners: the grid (page 1, redraw) and the search box. Mark collected items (`docs/work/2026-11-04-highlight-known/`) colors the collected items the Hide collected options leave in the list: `filters.IsCollected` (each category's own Hide collected check, the Already known line for items in no category) per drawn slot, then `MarkCollected` after `Tint` in `Gui/MerchantItemSlot.lua`; `KrowiEVU_Filters` profile `MarkCollected` (`Enabled` nil follows Already Known: on while it is loaded; `Look` Color, Gray or Custom; `Color`), switched in the filter menu under its own Collected items title, the custom color on the options page's Collected items tab (Krowi_Menu has no color swatch). Look Color reads Already Known's `AlreadyKnownSettings` (color, monochrome) while it is loaded: Already Known's own vendor tint lands on Blizzard's hidden `MerchantItem1-10` since 23.0. On vendor open, the `ResetSetMerchantFilter` post-hook (Retail and Forever) and Classic's `OnShow` hook (`Gui/FilterButton/FilterButtonMixin.lua`) apply RememberFilter. The filter and options menus are built with `addon.MenuBuilder` (Blizzard's Menu API on Retail, and on Forever through the builder config `modern = addon.Util.IsModern`, Krowi_Menu 2.2; a UIDropDownMenu frame on Classic; both inside Krowi_Menu).
