# What /kevutest does

From `CLAUDE.md`, Testing in game, which keeps how to deploy, run and read a run.

For one pass per client, run `.claude/tools/Run-GameTests.ps1 -Client <client>` with the character next to a vendor with more than one page (`-Vendor x,y` right-clicks the vendor on a spot of a `Send-GameInput.ps1 -Capture`; without it Krowi opens one), or Krowi types `/kevutest` there (`Tests/Tests.lua`, shipped like Krowi_AchievementFilter's tests; it starts when the vendor opens, or at once when one is open): it checks the window as it opened (the vendor's first draw when `/kevutest` was typed before opening it), then sets filter All (where it also checks that the new-player tutorial's buy arrow lands on slot 2 with Direction Rows, and works out Bulk Purchase's room in the bags without buying and checks it against its own count from the bags, for the first item and on Retail and Forever the first crafting reagent, with every bag's type and slot noted), page 2, a custom filter, a search, a larger grid from the last page and the grid back, the Gear options, an item level range from the vendor's own levels (skipped on Era and Anniversary), Gold total off with Hide currencies you have none of on, sorting by name, gold price (also reversed), token price (with the token banner's order) and quality, each checked pair by pair from the merchant API, and at a vendor with consumables of type Other Hide collected, Illusions on (cross-checked with the illusion collection by name, with the first items' tooltip lines noted), Hide collected Recipes and Other on (a recipe or uncategorized item hidden exactly when Already known, the Already known check against the mount and toy collections, the first recipes' tooltip lines, the items it hides with their category and the list's build time noted), Mark collected items with every Hide collected option off (a slot marked exactly when collected, none with the option off), shows the options button's Hide-message arrow in its banner, turns on the gear's first-time highlight and checks it shown, then gone after the click handler, then waits up to 30 s each for a click on a currency in the token banner (the character window's Currency tab, PvP on TBC, nothing on Era; skipped without a currency), a hover on the repair-all button and on an item, and clicks on Buyback and Merchant. Each step is checked from the frames (slots and their items, page controls, Blizzard's hidden slots, the ElvUI, GW2_UI, EllesmereUI, CanIMogIt and Transmog Loot Helper evidence when those are on, the token banner visible and against the costs of the list, Scrap's button inside the window with the repair-all button on one anchor on the Classic clients, the server's item count for the addon's filters against All, and under All Hide collected for placed decor and the recipe record) and screenshotted with the step named in a banner above the window; the filter, search, grid and the Gear, token banner and Hide collected Illusions, Recipes and Other options go back at the end, and the last two steps check Krowi_Util's client flags against what the client's `WOW_PROJECT_ID` should give and list this addon's Lua errors of the session from BugGrabber, also those from before the run. On WoW Forever run it with the gamepad interface off; with it on, check by hand that Blizzard's window and the chat line show. The last 10 runs are kept (`KrowiEVU_Debug.Tests.Runs`), so a series of runs, one per skin addon with a reload between each, is read in one go afterwards. After the next `/reload`, `.claude/tools/Read-GameTests.ps1 -Client <client>` prints every run's checks with each step's screenshot path, to open with the Read tool, and a summary line per run; `Run-GameTests.ps1` types that `/reload` and prints the newest run. The routine never clicks or hovers by itself: with the kit's marker addon loaded (`KrowiGameInput`) each mouse step asks the kit for its click or hover once and clears the request when the step is over, and a run tells the kit when it is done however it ended; the kit's `Send-GameInput.ps1 -WaitForDone` serves them under its own guard (clicks only in a client the kit started). Without the marker a person does those steps (docs/work/2026-11-27-kevutest-input).
