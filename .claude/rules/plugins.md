# Public API and plugins

From `CLAUDE.md`, Architecture, which keeps the summary and the API's stable contracts.

- **Public API** (`Api/`): the global `KrowiEVU` with `PluginsApi` (`RegisterPlugin`, `RegisterEvent`, `LoadPluginLocalization`, `CallPlugins`) and `UtilApi.InjectOptions`. The item slot plugin methods (`OnItemSlotCreated`, `OnFirstDraw`, `OnItemSlotUpdated`, `OnItemSlotsUpdated`) are public and documented at the top of `Api/PluginsApi.lua`: keep their signatures stable. Built-in plugins: `Plugins/CanIMogIt.lua` (attaches CanIMogIt's overlay to the addon's slots and refreshes it on every draw and on CanIMogIt's own `OptionUpdate` and `ResetCache` messages), `Plugins/ElvUI.lua` (on Classic the addon's own ElvUI slot skin when a slot is created, then on every client the steps of ElvUI v16's one merchant skin, `ElvUI/Game/Shared/Skins/Merchant.lua`, on a slot's first draw, as both ran in 22.2; ElvUI skins at `PLAYER_LOGIN`, so the page controls and the buyback re-layout for ElvUI before v16 wait for `OnFirstDraw`; when ElvUI's merchant skin changes, follow it here), `Plugins/GW2_UI.lua` (GW2_UI's merchant skin steps through its `GW2_ADDON` helpers), `Plugins/TransmogLootHelper.lua` (from its author's PR #97: calls TLH's public `UpdateOverlay` after each draw; TLH 12.1.5-02 and later draws on `KrowiEVU_MerchantItem<N>` itself, Retail and Forever), `Plugins/EllesmereUI.lua` (Retail only: EllesmereUI's merchant tile and item levels, drawn by the plugin itself because EllesmereUI's skin engine is private and its code all rights reserved) and `Plugins/Scrap.lua` (Classic clients, #80: Scrap anchors its merchant button left of `MerchantRepairItemButton`, which this layout moves to the inset's left edge, and with guild repair gives `MerchantRepairAllButton` a second anchor; a post-hook on Scrap's `UpdatePosition`, hooked when Scrap's load-on-demand `Scrap_Merchant` loads at the first vendor (`ADDON_LOADED`), re-runs the repair layout and puts Scrap's button right of the last repair button; the file returns at its top on Retail and Forever, where Scrap sits on Sell All Junk). Plumber's Merchant Price module moves `MerchantMoneyInset`, the token banner's parent, into a hidden frame and reads only Blizzard's `MerchantItemN`; since Plumber 1.9.7 it stays off while this addon is loaded (`C_AddOns.IsAddOnLoaded`, so also when the addon steps aside; Plumber #533), so the notice plugin #100 added in 24.2 was dropped before release (Krowi, 2026-10-29). A skin plugin is built only for the clients the skinned addon's current release supports (Krowi, 2026-10-18). Skins on WoW Forever are not supported yet: `Plugins/ElvUI.lua` and `Plugins/GW2_UI.lua` return at their top there, so the grid stays unskinned (Krowi, 2026-10-21). Krowi_Vendorer reads `KrowiEVU_MerchantItemsContainer` (`Api/Api.lua:8`) to step aside and calls its `HideAll()`, which hides the addon's slots and page controls and Blizzard's `MerchantItem1-12`; keep both.
